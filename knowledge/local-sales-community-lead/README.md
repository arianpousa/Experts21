# Knowledge: Javier, Local Sales & Community Lead (`local-sales-community-lead`)

Javier reads this folder before every answer. Put documents here that are specific to this role and to this firm.

## What belongs here

- Relationship maps
- Association and event notes
- Local client meeting notes
- Proposals sent

## What does not

- General research shared by the whole team: that goes in `docs/`.
- Passwords, API keys, Social Security or tax ID numbers, bank details, medical records (see `knowledge/README.md`).

## Conventions

- File names: `YYYY-MM-DD-short-title.md`.
- First lines of each file: **Source:**, **Date:**, **Confidentiality:**.
- When a newer document replaces an older one, keep the old one only if its history matters; otherwise delete it.
