# Knowledge: Luis, Puerto Rico Tax & Accounting Specialist (CPA) (`pr-tax-accounting-specialist`)

Luis reads this folder before every answer. Put documents here that are specific to this role and to this firm.

## What belongs here

- Chart of accounts
- Filed Puerto Rico returns and IVU returns (summaries)
- Hacienda notices
- CPA certifications
- Municipal patente and CRIM filings

## What does not

- General research shared by the whole team: that goes in `docs/`.
- Passwords, API keys, Social Security or tax ID numbers, bank details, medical records (see `knowledge/README.md`).

## Conventions

- File names: `YYYY-MM-DD-short-title.md`.
- First lines of each file: **Source:**, **Date:**, **Confidentiality:**.
- When a newer document replaces an older one, keep the old one only if its history matters; otherwise delete it.
