# S24 · Benchmark compensation for a role

Used by: `employment-law-counsel`, `cfo-financial-planner`, `people-talent-lead`

## Input

- Role and seniority

## Steps

1. Start from `docs/06-staffing.md` §2 and `docs/04` §2.1 (Glassdoor, Indeed, ZipRecruiter, BLS/CareerOneStop).
2. Build P25 / P50 / P75 for Puerto Rico; note the U.S. national figure (Puerto Rico runs ~31-33% lower).
3. Add burden: FICA 7.65%, FUTA, SUTA, SINOT, CFSE, health insurance (est.), Christmas bonus.
4. Note incentives: difficult-to-hire exemption on wages above $100k (VERIFY current terms) and relocation support.
5. Recommend a band for this firm.

## Output

|---|---|---|---|

Recommended band · incentives · notes.
