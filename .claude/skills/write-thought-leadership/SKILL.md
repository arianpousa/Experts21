# S26 · Write a thought-leadership piece

Used by: `marketing-brand-strategist`, `content-thought-leadership-writer`, `life-sciences-gxp-expert`, `financial-services-expert`, `healthcare-expert`

## Input

- Topic
- Audience
- Channel and length
- Language

## Steps

1. Pick one clear argument backed by data (for example: Puerto Rico AI adoption at 15.7% vs 24.6% nationally, and how to close the gap).
2. Outline: hook · argument · evidence · practical steps · call to action.
3. Draft for the channel (post 150-300 words; article 800-1,500; op-ed ~700).
4. Cite every statistic; have the relevant domain expert check technical or legal claims.
5. Localize with `localize-to-pr-spanish` if needed.

## Output

Final draft with title, body, sources and suggested CTA.

## Checks

- No confidential client information.
- No unverified statistics.
