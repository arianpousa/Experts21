# S28 · Build a target-account list and outreach sequence

Used by: `export-sales-lead`, `partnerships-alliances-manager`

## Input

- ICP (from `build-ideal-client-profile`)
- Vertical
- Offer

## Steps

1. Select 50-200 accounts that match the ICP; record why each fits and its expected tag.
2. Identify 2-3 buyer roles per account.
3. Note trigger signals (hiring, funding, expansion, regulation).
4. Write a 5-7 touch sequence over 3-4 weeks (email, LinkedIn, call), leading with the AI Readiness Assessment offer.
5. Define CRM fields: account, persona, trigger, tag, stage, next step.

## Output

Account table (account, why it fits, tag, buyers, trigger) · Sequence (touch, day, channel, message) · CRM fields.

## Checks

- Drafts only: do not send messages.
- Follow CAN-SPAM and LinkedIn terms; public business data only.
