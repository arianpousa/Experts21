# S03 · Profile a competitor

Used by: `market-research-analyst`, `competitive-intelligence-analyst`, `marketing-brand-strategist`, `partnerships-alliances-manager`

## Input

- Competitor name and website

## Steps

1. Check `docs/03-competitors.md` for an existing entry.
2. Gather: offers, verticals, named clients and case studies, headcount (LinkedIn), partners (Microsoft, AWS...), certifications, Puerto Rico government registrations (RUL/RPT), pricing signals, hiring activity, reviews (Clutch).
3. Compare with our positioning (`docs/07-marketing.md` §1): where they are stronger, weaker or absent.
4. Rate threat (H/M/L) per segment and recommend compete, avoid or partner.
5. Update `docs/03-competitors.md` if facts changed.
