# S16 · Build an RFP or vendor-registration compliance matrix

Used by: `corporate-commercial-attorney`, `cfo-financial-planner`, `public-sector-procurement-expert`

## Input

- RFP or registry requirements

## Steps

1. Extract every mandatory requirement ('shall', 'must'), evaluation criterion, form, certificate and deadline (questions, submission).
2. Include standard Puerto Rico government documents: RUL certificate, RPT registration, Hacienda, CRIM, Labor and ASUME certificates, Department of State good standing, notarized affidavit (ASG-633), insurance, bonds, SAM.gov if federal funds.
3. Map each to evidence and owner; mark gaps.
4. Note payment terms and risk factors for the go/no-go decision.

## Output

| # | Requirement | Section | Evidence / response | Owner | Status |
|---|---|---|---|---|---|

Go/no-go notes: deadlines, gaps, payment risk.

## Checks

- Quote the RFP's wording.
- Missing one mandatory document usually disqualifies the bid.
