# S37 · Create a project plan and status report

Used by: `engagement-lead`, `delivery-engagement-manager`, `operations-continuity-manager`

## Input

- Goals and scope
- Team and stakeholders
- Deadlines

## Steps

1. Plan: objectives, scope (in and out), milestones, RACI (including which agents own what), risks, communication cadence.
2. Status: RAG rating, progress vs plan, decisions needed, risks and issues, next steps.
3. Keep a decision log (date, decision, owner, rationale).
4. Save under `deliverables/<project>/` when asked for files.

## Output

Plan document · weekly status (RAG, done, next, decisions, risks) · decision log.

## Checks

- Show slippage honestly.
- Every action has an owner and date.
