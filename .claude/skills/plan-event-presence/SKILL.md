# S29 · Plan an event presence

Used by: `marketing-brand-strategist`, `local-sales-community-lead`, `partnerships-alliances-manager`, `people-talent-lead`

## Input

- Event (for example Caribbean AI Summit, Cámara de Comercio Techno Tuesday, CIAPR hiring fair)
- Goals

## Steps

1. Set goals: meetings booked, leads, hires, content.
2. Choose format: attend, speak, sponsor, workshop, booth. Estimate budget.
3. Pre-event: list target attendees and book meetings; prepare bilingual materials.
4. On site: who goes, schedule, lead capture.
5. Follow up within 48 hours; report results vs goals.

## Output

Event plan (goals, format, budget, target list, materials, staffing, follow-up) · post-event report.

## Checks

- Check event dates on the official site.
- Separate recruiting goals from sales goals.
