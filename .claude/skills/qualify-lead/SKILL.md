# S22 · Qualify a lead

Used by: `business-strategist`, `export-sales-lead`, `local-sales-community-lead`, `partnerships-alliances-manager`, `sme-market-specialist`

## Input

- Lead information and notes from discovery

## Steps

1. Score 1-5 each: ICP fit; pain and urgency; budget; authority; timing; data readiness; tax tag (EXPORT = 5, LOCAL = 3, unclear = 1); strategic value (logo, vertical, case study); risk (payment, scope, government).
2. Weighted total: fit 20%, pain 15%, budget 15%, authority 10%, timing 10%, data 10%, tag 10%, strategic 5%, risk 5%.
3. Go if ≥ 3.5; nurture if 2.5 to 3.5; no-go below 2.5.
4. Name the next step and owner.

## Output

| Criterion | Score | Evidence |
|---|---|---|

**Total:** x.x. **Decision:** go / nurture / no-go. **Next step:**

## Checks

- Base scores on evidence from the client, not hope.
- Get the tag confirmed with `tag-export-or-local`.
