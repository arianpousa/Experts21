# S41 · Write a job description and interview loop

Used by: `employment-law-counsel`, `ml-llm-engineering-lead`, `people-talent-lead`

## Input

- Role need
- Seniority
- Salary band (from `benchmark-compensation`)

## Steps

1. Job description: mission, responsibilities, must-have and nice-to-have skills, location (on-island in Puerto Rico), band, benefits. English and Spanish.
2. Interview loop: screen · technical (for engineers: a practical LLM/RAG exercise) · system design · client-facing case · values.
3. Scorecard per stage with 3-5 criteria and a 1-4 scale.
4. Have employment counsel check for prohibited questions and required notices.

## Output

Job description (EN/ES) · interview plan · scorecards.

## Checks

- Use job-related criteria only.
- State pay range and on-island requirement clearly.
