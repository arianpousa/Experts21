# S25 · Write positioning and messaging

Used by: `competitive-intelligence-analyst`, `marketing-brand-strategist`, `export-sales-lead`, `local-sales-community-lead`

## Input

- Audience/persona
- Offer
- Competitors in play

## Steps

1. Start from `docs/07-marketing.md` §1 and `docs/03-competitors.md`.
2. Write one-sentence positioning: for [audience] who [need], we [offer] unlike [alternative] because [proof].
3. Three differentiators, each with proof (cited data, credentials, case studies we really have).
4. Objections and answers (for example 'Is Puerto Rico offshore?' → U.S. jurisdiction, U.S. law, Eastern time).
5. Call to action (usually the AI Readiness Assessment).

## Output

Positioning statement · Differentiators + proof · Objections and responses · CTA · Spanish version (if requested).

## Checks

- No claims we cannot prove.
- Do not promise on-site mainland presence by default.
