# S27 · Localize content into Puerto Rico Spanish

Used by: `employment-law-counsel`, `marketing-brand-strategist`, `content-thought-leadership-writer`, `local-sales-community-lead`, `healthcare-expert`, `public-sector-procurement-expert`, `sme-market-specialist`

## Input

- English source text
- Audience (business, government, consumer, employee)

## Steps

1. Use 'usted' for business and government; adjust for consumer tone.
2. Use local terms: Hacienda, planilla, patente, PyMEs, CRIM, decreto, comerciante, Registro Único de Licitadores.
3. Keep English tech terms that Puerto Rico professionals use ('software', 'cloud', 'machine learning') when natural; translate them for consumer audiences.
4. Use official names for agencies and laws; adapt examples, dates and number formats.
5. Read the result aloud as a local reader would; fix anything that sounds translated.

## Output

Spanish text + a short glossary of choices made.

## Checks

- Legal and HR documents need review by licensed counsel.
- Do not translate proper names of programs or laws.
