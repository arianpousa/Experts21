# S04 · Build an ideal client profile

Used by: `market-research-analyst`, `marketing-brand-strategist`, `export-sales-lead`, `local-sales-community-lead`, `sme-market-specialist`

## Input

- Segment
- Won/lost deals or research

## Steps

1. Start from `docs/02-target-customers.md` (segments, personas, tagging rules).
2. Define firmographics: industry, size, revenue, location, tech stack, data maturity.
3. Set the tax tag and the reason (where the client entity is and where the benefited operations are).
4. List buyer roles (economic buyer, champion, blockers) with pains and success metrics.
5. List buying triggers (reshoring expansion, new AI policy, a regulator finding, leadership change) and disqualifiers.
6. Say where to find these accounts (lists, associations, events, partners).

## Checks

- Base it on evidence; mark hypotheses (est.).
- Name the segment's tax tag explicitly.
