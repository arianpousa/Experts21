# S39 · Assess a risk

Used by: `engagement-lead`, `business-strategist`, `ai-governance-regulatory-advisor`, `risk-compliance-officer`, `cfo-financial-planner`, `operations-continuity-manager`

## Input

- Risk or decision description

## Steps

1. Check `docs/08-risks.md` for an existing entry.
2. Describe cause → event → consequence.
3. Rate likelihood and impact (L/M/H) with reasons.
4. List existing controls and new mitigations; name the owner agent; set an early-warning trigger and review date.
5. Add or update the row in `docs/08-risks.md` when asked.

## Output

| # | Risk | Likelihood | Impact | Mitigation | Owner agent |
|---|---|---|---|---|---|

(matches the format of docs/08-risks.md) + trigger and review date.

## Checks

- Be specific; avoid generic risks.
- Escalate anything that threatens the decree or the founders' residency.
