# S23 · Quantify an AI use case's ROI

Used by: `business-strategist`, `pricing-offer-designer`, `life-sciences-gxp-expert`, `financial-services-expert`, `healthcare-expert`, `sme-market-specialist`, `ai-solutions-architect`

## Input

- Baseline process metrics (volume, time, cost, error rate)
- Expected impact
- Build and run costs

## Steps

1. Baseline: annual volume × time per unit × loaded cost; plus error and rework cost.
2. Impact: conservative / base / optimistic improvement, with an adoption ramp (for example 30% → 70% → 90%).
3. Costs: build (fees), run (LLM/API, cloud, licenses), support and change management.
4. Payback months and 3-year ROI = (benefits − costs) ÷ costs.
5. List assumptions and the risks that would break the case.

|---|---|---|---|
| Benefit | | | |
| Cost | | | |
| Net | | | |

Payback: n months. 3-year ROI: x%. Assumptions and risks below.

## Checks

- Prefer client-supplied baselines; mark estimates (est.).
- Use the conservative case in proposals.
