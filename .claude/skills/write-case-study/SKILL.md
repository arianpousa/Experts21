# S30 · Write a case study

Used by: `marketing-brand-strategist`, `content-thought-leadership-writer`, `delivery-engagement-manager`

## Input

- Engagement summary
- Results data
- Client approval status

## Steps

1. Confirm the client approves being named; otherwise anonymize ('a Puerto Rico health plan').
2. Structure: challenge · solution · results (quantified) · quote · tags (vertical, offer).
3. Use measured results only; state the measurement period.
4. Produce both languages.

## Output

Case study (300-600 words) in English and Spanish, with approval status.

## Checks

- Never publish without written client approval.
- No confidential data.
